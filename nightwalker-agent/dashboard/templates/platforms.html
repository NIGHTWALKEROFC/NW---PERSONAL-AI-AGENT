Run a connector

This page shows status only — starting/stopping a live connector is done from the terminal:

python scripts/run_telegram_bot.py

python scripts/run_instagram_bot.py

python scripts/run_whatsapp_bot.py

Instagram and WhatsApp also need python scripts/run_webhook_server.py running at the same time (and reachable by Meta) — they receive messages by webhook push, not polling. Telegram doesn't need this.
