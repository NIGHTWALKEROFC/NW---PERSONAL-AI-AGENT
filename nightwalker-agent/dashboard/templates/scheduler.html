Scheduler

Background housekeeping jobs — pure local database hygiene (expired sessions, old login attempts, consumed webhook queue rows, overdue tasks). None of these send a message or contact a platform, so they run independently of permissions and timing. The kill switch on the Security page stops this whole scheduler along with everything else.

What this does NOT do

This does not interpret task_memory's schedule or trigger_condition fields (e.g. "watch this conversation and let me know") — that requires a natural-language task planner (spec section 14) that doesn't exist yet. The one task_memory field this scheduler acts on is expires_at, sweeping overdue tasks to "expired".
